# Credit Card Fraud Detection

A machine learning project to detect fraudulent credit card transactions using a public dataset.

## 📊 Dataset
- [Kaggle Credit Card Fraud Dataset](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
- Contains anonymized transactions made by European cardholders in September 2013.

## ⚙️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## 🧠 Model
- Used RandomForestClassifier for classification
- Evaluated model using Accuracy, Confusion Matrix, and ROC AUC
